# Bank Account Manager

A Python project that simulates a simple bank account management system.

## Features

* User login with username and password
* Hidden password input
* Balance display
* Add a card
* Remove a card
* Display customer information
* Logout
* Invalid menu choice handling
* Login retry after incorrect credentials

## What I Practiced

This project helped me practice:

* Dictionaries and nested dictionaries
* Sets
* Functions
* `if`, `elif`, and `else`
* `while` loops
* `for` loops
* User input
* Modules and imports
* The `getpass` module
* Returning values from functions
* Working with data stored in dictionaries

## Versions

### Version 1

### Version 2

## How to Run

Make sure Python is installed, then run:

```bash
python bank_manager_v2.py
```

This is a learning project created to practice Python programming and gradually improve an existing program instead of building it from scratch each time.
